## Why this repo exists

I knew the only way that I'd land a job was to perform strongly in technical interviews. Given that, I decided to challenge myself by setting a goal to complete the Neetcode 150. My submissions are auto-committed the second I solve a problem, whether they're ugly or not.

## Repo structure

Organized by topic, then problem, then attempt, so you can watch the struggle before the breakthrough:

```
<topic-folder>/
  <problem-id>/
    submission-0.py   (first attempt, sometimes rough)
    submission-1.py   (the fix)
    ...
```

**Example:**
```
Data Structures & Algorithms/two-integer-sum/submission-0.py
Data Structures & Algorithms/binary-search/submission-0.py
```
